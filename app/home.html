ИИ-сюрвейер INSON

Расчёт ставки с объяснением, проверки по закону и тарифной политике, предписания страхователю, портфельный аудит, динамика рынка и ёмкость компании — в одном месте.

Что делать

Новый расчёт

Объект, риски, документы — и сразу ставка, премия, что удешевит и что предписать страхователю.

Открыть → Портфельный аудит

Загрузите Excel-выгрузку договоров — система найдёт занижения, превышения и договоры без франшизы.

Загрузить файл → Запросы и админка

Список запросов с вердиктами, версии тарифов, коэффициенты, продукты, журнал действий.

Открыть → Динамика рынка

Квартальные отчёты НАПП подтягиваются сами. Премии, убыточность, средняя ставка по классам.

Смотреть → Ёмкость и удержание

Лимиты по Положению 1806, резервы и активы по Положению 1882, удержание по классам.

Открыть → Калибровка

Пересчёт ставок по накопленным убыткам: предложение → утверждение → новая версия тарифа.

Открыть → Паутина знаний

Продукты, классы, учётные группы и правила РНП — одной картой.

Открыть → Офис агентов

Кто из агентов чем занят прямо сейчас.
