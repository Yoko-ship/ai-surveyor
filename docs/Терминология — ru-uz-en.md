# Терминология для интерфейса: ru / uz-latn / en

Назначение: единый словарь для трёхъязычного интерфейса и для автоопределения типа загруженного документа.

Главное для практики: узбекские термины берём из официальных текстов актов на узбекском языке (lex.uz), а не переводим сами. Английские термины нормой РУз не закреплены — это рабочий перевод для интерфейса, он помечен отдельно.

## 4. Нормализация узбекской латиницы — правило для кода

Проблема: одно и то же слово пишут по-разному — `sug‘urta`, `sug'urta`, `sugʻurta`, `sugurta`, `суғурта`. Сравнивать нужно нормализованные ключи, а не исходный текст.

Порядок нормализации (применять одинаково и к тексту документа, и к маркерам словаря):

1. Unicode NFC, затем lowercase.
2. Убрать все варианты апострофа: `ʻ` U+02BB, `ʼ` U+02BC, `‘` U+2018, `’` U+2019, `'` U+0027, `` ` `` U+0060, `´` U+00B4, `ʹ` U+02B9. Не заменять на канонический, а удалять: `oʻ → o`, `gʻ → g`, `maʼlumot → malumot`. Так все написания схлопываются в одно.
3. Кириллицу транслитерировать в латиницу: а a, б b, в v, г g, ғ g, д d, е e, ё yo, ж j, з z, и i, й y, к k, қ q, л l, м m, н n, о o, п p, р r, с s, т t, у u, ў o, ф f, х x, ҳ h, ц ts, ч ch, ш sh, ъ (удалить), ь (удалить), э e, ю yu, я ya.
4. Свернуть «шумные» различия: `x → h` (техник / tehnik / texnik), `ts → s` (ассистанс / assistans), начальное `ye → e`, `w → v`.
5. Дефисы, точки, запятые, `№` и повторяющиеся пробелы → один пробел; обрезать края.
6. Сравнение — поиск подстроки в нормализованном тексте. Тип документа признаём при совпадении не менее двух разных маркеров этого типа; при равенстве очков у двух типов — «прочее» и вопрос пользователю.

Проверка на примерах: `Sugʻurta polisi`, `Sug'urta polisi`, `Sug‘urta polisi`, `Суғурта полиси`, `sugurta polisi` → все дают `sugurta polisi`. `Koʻchirma`, `ko'chirma`, `kochirma`, `кўчирма` → `kochirma`. `Texnik pasport`, `техник паспорт` → `tehnik pasport`.
