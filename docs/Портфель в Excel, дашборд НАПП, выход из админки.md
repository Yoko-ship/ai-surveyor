# Портфель в Excel, дашборд НАПП, выход из админки (задача 166, 22.09.2026)

## 1. Шаблон отчётности портфеля

`GET /portfolio/template.xlsx` (`?lang=uz` — заголовки и листы по-узбекски). Листы:

- **Портфель** (одна строка — один договор; * — обязательная, тёплая заливка):
  Номер договора*, Дата заключения, Дата начала*, Дата окончания*, Код продукта*, Класс страхования, Филиал, Регион*,
  Тип страхователя* (юрлицо/физлицо), ИНН юрлица, Тип объекта, Страховая сумма*, Стоимость объекта,
  Премия начисленная*, Премия оплаченная, Франшиза, Ставка % годовых, Сейсмозона (6–10), Валюта (UZS/USD/EUR/RUB),
  Статус договора* (действует/расторгнут/истёк), Число убытков, Заявлено по убыткам, Выплачено по убыткам, Дата последнего убытка.
- **Убытки**: Номер договора*, Номер убытка, Дата события*, Дата заявления, Заявлено*, Выплачено, Статус убытка* (заявлен/оплачен/отказ), Причина / риск.
- **Инструкция**: как заполнять, таблица колонок с примерами, обязательные выделены.
- **Справочники**: продукты, классы, регионы (из `market_stats`), типы объектов (`base_rates`), причины (`perils` + общие), значения списков.
  Выпадающие списки на листах ссылаются сюда.

ФИО не вносится вообще; ИНН — только юрлица (у физлица — ошибка, значение не выводится и не хранится).

Загрузка: `POST /portfolio/preview` (разбор без сохранения: ошибки и предупреждения по строкам — лист, строка, колонка, текст;
сводка) → `POST /portfolio/import`. Шаблон с ошибками не сохраняется (400, `detail = {message, errors}`); выгрузка
учётной системы старого вида загружается как раньше, ошибки становятся пометками строк.
Хранение: `portfolio_contracts`, `portfolio_claims` (новые таблицы), проверка движком — как раньше в `portfolio_reviews`.
Сводка: `GET /portfolio/batches/{id}/overview`, `GET /portfolio/overview` (последняя загрузка) — договоры, суммы, премии,
оплата, убытки и убыточность всего, по классам и регионам. Суммы — только по договорам в сумах (курса в отчёте нет).

## 2. Дашборд /stats

Вкладки «Дашборд» (по умолчанию) и «Конструктор» (прежняя страница, поднимается при первом открытии; старые ссылки
`#tab=…&rows=…` открывают конструктор). Фильтры: период, класс (или пакет), регион. Карточки: премии, выплаты, убыточность,
число страховщиков, доля добровольного/обязательного, доля и место INSON — у каждой изменение к срезу годом раньше.
Графики (inline SVG/CSS, без внешних библиотек): премии и выплаты по кварталам / с начала года, убыточность по классам,
структура по классам (кольцо), топ-10 страховщиков с INSON, регионы с долей и проникновением (`/stat/indicators/penetration`,
если ВРП за год нет — прошлый год с пометкой). Под каждым графиком — плашка «Отчёты НАПП» (napp.uz).

## 3. Выход из админки — контракт для мини-аппа

Кнопка «Выйти из админки» на `/admin/hub` (шапка и низ рейки), `/admin`, `/admin/deploy` ведёт на **`/tg?mode=user`**.

`GET /tg/me?view=user` (или заголовок `X-View: user`) отвечает так, как увидел бы «сотрудник»:

| поле | в режиме user |
|---|---|
| `nav` | меню сотрудника (без «Настроек») |
| `can_edit` | `[]` |
| `rights` | права роли «сотрудник» |
| `user.role` / `user.is_admin` | `"сотрудник"` / `false` |
| `view` | `"user"` (без параметра — `"full"`) |
| `real_role` | настоящая роль, например `"админ"` |
| `admin_available` | `true`, если человек на самом деле админ → показать «Вернуться в админку» (ссылка `/admin/hub`) |

Это только отображение: сессия и права на сервере не меняются, админские API админа по-прежнему пускают.
Что делает мини-апп (дизайнер): при `mode=user` в адресе запрашивает `/tg/me?view=user`, прячет админские разделы
и формы правки, показывает плашку «Режим пользователя · Вернуться в админку», если `admin_available`.

Новые ключи словаря (в `app/i18n/*` их добавляет дизайнер; без них остаётся русский): `admin.exit`, `admin.exit_short`,
`portfolio.template`, `portfolio.upload`, `stats.tab_dash`, `stats.tab_builder`.
