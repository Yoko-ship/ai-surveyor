# Приложение А к ТЗ. Шаблоны анализа по классам страхования

Версия 1.0 от 27.09.2026. Универсальный шаблон: подходит любому страховщику, у которого классы заданы по закону.

## А.1. Общий принцип

Анализ для всех классов идёт по одной схеме из шести шагов. От класса к классу меняются только объект и набор рисков.

| Шаг | Что делает система | Одинаково для всех классов |
|---|---|---|
| 1 | Определяет объект | Да, меняются только поля объекта |
| 2 | Оценивает стоимость объекта | Да, меняется метод оценки |
| 3 | Выявляет риски | Да, меняется перечень рисков |
| 4 | Находит факторы, которые повышают и снижают риск | Да, меняется перечень факторов |
| 5 | Считает сценарии убытка и лимит удержания | Да, меняется правило сценария |
| 6 | Даёт ставку, франшизу и пояснение | Да |

Шаблон класса состоит из восьми полей:

1. Объект.
2. Обязательные данные, не более четырёх сверх общих.
3. Дополнительные данные.
4. Метод оценки стоимости.
5. Риски.
6. Факторы риска.
7. Правило сценария убытка.
8. Документы и внешняя статистика.

Общие обязательные данные для всех классов: продукт или класс, страховая сумма, стоимость объекта либо лимит ответственности, регион.

## А.2. Оценка стоимости объекта

Система оценивает стоимость сама и сравнивает её с заявленной. Методы применяются по порядку, пока один не даст результат.

| № | Метод | Когда применяется |
|---|---|---|
| 1 | Рынок | Есть не менее пяти объявлений не старше шести месяцев |
| 2 | Запрос официальному дилеру или поставщику | Рынка нет, объект серийный |
| 3 | Первоначальная стоимость минус износ | Известны цена и дата ввода в эксплуатацию |
| 4 | Отчёт независимого оценщика | Загружен в документах |
| 5 | Балансовая стоимость или счёт поставщика | Остальные методы не сработали |
| 6 | Лимит по договору или закону | Классы ответственности и финансовых рисков |

Правила:

- Если оценка отличается от заявленной больше порога, система показывает уточнённую стоимость с объяснением. Порог по умолчанию 15 %, меняется в настройках.
- Страховая сумма выше стоимости недопустима. Страховая сумма ниже стоимости означает пропорциональную выплату.
- У каждой цены есть ссылка на источник.
- Нормы износа задаёт страховщик. По умолчанию: здания 3 % в год, транспорт 20 %, компьютеры 20 %, мебель и оборудование 15 %.

## А.3. Шаблоны по классам

### Класс 1. Несчастные случаи

| Поле | Содержание |
|---|---|
| Объект | Человек или группа людей |
| Обязательные данные | Число застрахованных, профессия или вид деятельности, страховая сумма на человека |
| Дополнительные данные | Возраст, занятия спортом, круглосуточное покрытие или только рабочее время, убытки за 3 года |
| Оценка стоимости | Метод 6: сумма на человека, умноженная на число людей |
| Риски | Смерть, инвалидность, временная утрата трудоспособности, травма |
| Факторы риска | Опасность профессии, возраст, транспорт в работе, охрана труда |
| Сценарий убытка | Один случай: сумма на человека. Катастрофа: число людей в одном месте, умноженное на сумму |
| Документы и статистика | Список застрахованных без личных данных, сведения о травматизме. Смертность, производственный травматизм, пострадавшие в ДТП |

### Класс 2. На случай болезни

| Поле | Содержание |
|---|---|
| Объект | Человек или группа людей |
| Обязательные данные | Число застрахованных, программа покрытия, лимит на человека |
| Дополнительные данные | Возрастной состав, перечень клиник, франшиза, убытки за 3 года |
| Оценка стоимости | Метод 6: лимит на человека, умноженный на число людей |
| Риски | Амбулаторное лечение, стационар, экстренная помощь, критические заболевания |
| Факторы риска | Возраст, состав программы, частота обращений, уровень цен клиник |
| Сценарий убытка | Частотный: среднее число обращений, умноженное на средний счёт. Катастрофа: эпидемия |
| Документы и статистика | Программа, список клиник. Заболеваемость, смертность, обеспеченность врачами |

### Класс 3. Наземный транспорт

| Поле | Содержание |
|---|---|
| Объект | Автомобиль, грузовик, автобус, прицеп, самоходная спецтехника |
| Обязательные данные | Тип транспорта, марка и модель, год выпуска |
| Дополнительные данные | Пробег или моточасы, противоугонная система, водители и стаж, место хранения, убытки за 3 года, франшиза |
| Оценка стоимости | Методы 1, 2, 3 с поправкой на пробег или моточасы |
| Риски | ДТП, угон, пожар, стихия, противоправные действия третьих лиц, бой стёкол |
| Факторы риска | Возраст транспорта, стаж водителей, регион, условия работы спецтехники, хранение |
| Сценарий убытка | Частичный убыток: доля стоимости. Полный: гибель или угон. Катастрофа: несколько машин на одной стоянке |
| Документы и статистика | Техпаспорт или паспорт самоходной машины, фото с четырёх сторон. ДТП и пострадавшие по регионам, кражи |

Граница транспорта и спецтехники определяется по регистрационному документу, а не по виду машины.

### Класс 4. Железнодорожный подвижной состав

| Оценка стоимости | Методы 3, 4, 5 |
| Риски | Сход с рельсов, столкновение, пожар, стихия, повреждение при манёврах |
| Факторы риска | Возраст, состояние путей на маршруте, опасные грузы, сроки ремонтов |
| Сценарий убытка | Одна единица. Катастрофа: весь состав |
| Документы и статистика | Технический паспорт, акты ремонта. Объём перевозок по железной дороге |

## А.4. Порядок настройки шаблонов

1. Шаблоны хранятся в справочнике, а не в программе. Администратор меняет поля, риски и доли без участия разработчика.
2. Страховщик вправе убрать классы, по которым нет лицензии, и добавить свои продукты внутри класса.
3. Продукт из нескольких классов анализируется по каждому классу отдельно, премии складываются.
4. Все доли ущерба, веса и пороги помечены «не калибровано», пока страховщик не дал статистику убытков.
