# Приложение А к ТЗ. Шаблоны анализа по классам страхования

Версия 1.3 от 01.10.2026 (версия 1.2 — 01.10.2026, с классами страхования жизни: шаблоны отрасли жизни были добавлены по ошибке и удалены 01.10.2026; версия 1.1 — 01.10.2026, без класса 18; версия 1.0 — 27.09.2026). Универсальный шаблон: подходит любому страховщику, у которого классы заданы по закону.

Перечень классов взят из классификатора страховой деятельности: Постановление Кабинета Министров № 80 от 21.02.2022, приложение 6, п. 12 «Sugʻurta faoliyati klassifikatori» (редакция ПКМ № 458 от 23.07.2025, https://lex.uz/uz/docs/-5870213). Шаблоны составлены по всем классам отрасли «общее страхование» — классы 1–17 по Положению 1882, п. 10; класс 18 — по классификатору ПКМ № 80; и варианты 13з и 16у. Классы страхования жизни в приложение не входят. Приложение к постановлению опубликовано только на узбекском языке: русское название класса 18 — перевод разработчика.

## А.1. Общий принцип

Анализ для всех классов идёт по одной схеме из шести шагов. От класса к классу меняются только объект и набор рисков.

| Шаг | Что делает система | Одинаково для всех классов |
|---|---|---|
| 1 | Определяет объект | Да, меняются только поля объекта |
| 2 | Оценивает стоимость объекта | Да, меняется метод оценки |
| 3 | Выявляет риски | Да, меняется перечень рисков |
| 4 | Находит факторы, которые повышают и снижают риск | Да, меняется перечень факторов |
| 5 | Считает сценарии убытка и лимит удержания | Да, меняется правило сценария |
| 6 | Даёт ставку, франшизу и пояснение | Да |

Шаблон класса состоит из восьми полей:

1. Объект.
2. Обязательные данные, не более четырёх сверх общих.
3. Дополнительные данные.
4. Метод оценки стоимости.
5. Риски.
6. Факторы риска.
7. Правило сценария убытка.
8. Документы и внешняя статистика.

Общие обязательные данные для всех классов: продукт или класс, страховая сумма, стоимость объекта либо лимит ответственности, регион.

## А.2. Оценка стоимости объекта

Система оценивает стоимость сама и сравнивает её с заявленной. Методы применяются по порядку, пока один не даст результат.

| № | Метод | Когда применяется |
|---|---|---|
| 1 | Рынок | Есть не менее пяти объявлений не старше шести месяцев |
| 2 | Запрос официальному дилеру или поставщику | Рынка нет, объект серийный |
| 3 | Первоначальная стоимость минус износ | Известны цена и дата ввода в эксплуатацию |
| 4 | Отчёт независимого оценщика | Загружен в документах |
| 5 | Балансовая стоимость или счёт поставщика | Остальные методы не сработали |
| 6 | Лимит по договору или закону | Классы ответственности и финансовых рисков, личное и медицинское страхование (страховая сумма на человека или лимит программы) |
| — | Стоимость урожая: площадь × средняя урожайность за 5 лет × цена единицы продукции | Вариант 16у, урожай сельхозкультур |

Правила:

- Если оценка отличается от заявленной больше порога, система показывает уточнённую стоимость с объяснением. Порог по умолчанию 15 %, меняется в настройках.
- Страховая сумма выше стоимости недопустима. Страховая сумма ниже стоимости означает пропорциональную выплату.
- У каждой цены есть ссылка на источник.
- Нормы износа задаёт страховщик. По умолчанию: здания 3 % в год, транспорт 20 %, компьютеры 20 %, мебель и оборудование 15 %.

## А.3. Шаблоны по классам

### Класс 1. Несчастные случаи

| Поле | Содержание |
|---|---|
| Объект | Человек или группа людей |
| Обязательные данные | Число застрахованных, профессия или вид деятельности, страховая сумма на человека |
| Дополнительные данные | Возраст, занятия спортом, круглосуточное покрытие или только рабочее время, убытки за 3 года |
| Оценка стоимости | Метод 6: сумма на человека, умноженная на число людей |
| Риски | Смерть, инвалидность, временная утрата трудоспособности, травма |
| Факторы риска | Опасность профессии, возраст, транспорт в работе, охрана труда |
| Сценарий убытка | Один случай: сумма на человека. Катастрофа: число людей в одном месте, умноженное на сумму |
| Документы и статистика | Список застрахованных без личных данных, сведения о травматизме. Смертность, производственный травматизм, пострадавшие в ДТП |

### Класс 2. На случай болезни

| Поле | Содержание |
|---|---|
| Объект | Человек или группа людей |
| Обязательные данные | Число застрахованных, программа покрытия, лимит на человека |
| Дополнительные данные | Возрастной состав, перечень клиник, франшиза, убытки за 3 года |
| Оценка стоимости | Метод 6: лимит на человека, умноженный на число людей |
| Риски | Амбулаторное лечение, стационар, экстренная помощь, критические заболевания |
| Факторы риска | Возраст, состав программы, частота обращений, уровень цен клиник |
| Сценарий убытка | Частотный: среднее число обращений, умноженное на средний счёт. Катастрофа: эпидемия |
| Документы и статистика | Программа, список клиник. Заболеваемость, смертность, обеспеченность врачами |

### Класс 3. Наземный транспорт

| Поле | Содержание |
|---|---|
| Объект | Автомобиль, грузовик, автобус, прицеп, самоходная спецтехника |
| Обязательные данные | Тип транспорта, марка и модель, год выпуска |
| Дополнительные данные | Пробег или моточасы, противоугонная система, водители и стаж, место хранения, убытки за 3 года, франшиза |
| Оценка стоимости | Методы 1, 2, 3 с поправкой на пробег или моточасы |
| Риски | ДТП, угон, пожар, стихия, противоправные действия третьих лиц, бой стёкол |
| Факторы риска | Возраст транспорта, стаж водителей, регион, условия работы спецтехники, хранение |
| Сценарий убытка | Частичный убыток: доля стоимости. Полный: гибель или угон. Катастрофа: несколько машин на одной стоянке |
| Документы и статистика | Техпаспорт или паспорт самоходной машины, фото с четырёх сторон. ДТП и пострадавшие по регионам, кражи |

Граница транспорта и спецтехники определяется по регистрационному документу, а не по виду машины.

### Класс 4. Железнодорожный подвижной состав

| Поле | Содержание |
|---|---|
| Объект | Локомотив, вагон, цистерна, состав |
| Обязательные данные | Тип подвижного состава, год постройки, число единиц |
| Дополнительные данные | Маршруты, перевозимые грузы, сроки ремонта, убытки за 3 года |
| Оценка стоимости | Методы 3, 4, 5 |
| Риски | Сход с рельсов, столкновение, пожар, стихия, повреждение при манёврах |
| Факторы риска | Возраст, состояние путей на маршруте, опасные грузы, сроки ремонтов |
| Сценарий убытка | Одна единица. Катастрофа: весь состав |
| Документы и статистика | Технический паспорт, акты ремонта. Объём перевозок по железной дороге |

### Класс 5. Авиационное страхование

| Поле | Содержание |
|---|---|
| Объект | Самолёт, вертолёт, беспилотный аппарат |
| Обязательные данные | Тип и модель, год выпуска, вид эксплуатации |
| Дополнительные данные | Налёт часов, квалификация экипажа, база, география полётов, убытки за 5 лет |
| Оценка стоимости | Методы 4, 5, согласованная стоимость |
| Риски | Гибель, повреждение при взлёте и посадке, на земле, столкновение с птицами, пожар |
| Факторы риска | Возраст борта, налёт экипажа, тип аэродромов, техническое обслуживание |
| Сценарий убытка | Полная гибель борта. Перестрахование требуется почти всегда |
| Документы и статистика | Сертификат лётной годности, сведения об экипаже. Объём авиаперевозок |

### Класс 6. Морское страхование

| Поле | Содержание |
|---|---|
| Объект | Судно, катер, плавучее средство |
| Обязательные данные | Тип судна, год постройки, район плавания |
| Дополнительные данные | Класс судна, экипаж, сезон, убытки за 5 лет |
| Оценка стоимости | Методы 4, 5, согласованная стоимость |
| Риски | Гибель, посадка на мель, столкновение, пожар, шторм |
| Факторы риска | Возраст, район и сезон плавания, квалификация экипажа |
| Сценарий убытка | Полная гибель судна |
| Документы и статистика | Судовые документы, акт освидетельствования. Открытых данных мало, применяется оценка андеррайтера |

### Класс 7. Имущество в пути, грузы

| Поле | Содержание |
|---|---|
| Объект | Груз в перевозке |
| Обязательные данные | Вид груза, вид транспорта, маршрут |
| Дополнительные данные | Упаковка, число перевалок, охрана, температурный режим, убытки за 3 года |
| Оценка стоимости | Метод 5: счёт поставщика плюс перевозка и ожидаемая прибыль в согласованных пределах |
| Риски | Повреждение, утрата, кража, подмочка, порча, авария транспорта |
| Факторы риска | Хрупкость и ценность груза, длина маршрута, перевалки, страны транзита |
| Сценарий убытка | Одна отправка. Катастрофа: накопление на одном складе или транспорте |
| Документы и статистика | Счёт, договор перевозки, упаковочный лист. Объёмы перевозок, ДТП, кражи |

### Класс 8. Имущество от огня и стихийных бедствий

| Поле | Содержание |
|---|---|
| Объект | Здание, сооружение, оборудование, товарные запасы |
| Обязательные данные | Тип объекта, конструкция, деятельность на объекте |
| Дополнительные данные | Противопожарная защита, сейсмическая зона, износ, этажность, площадь, расстояние до пожарной части, противопожарные отсеки, соседние здания, перерыв в производстве, убытки за 3 года, франшиза |
| Оценка стоимости | Недвижимость: методы 1, 4, 3 с индексом цен на строительство. Оборудование: методы 2, 3, 5 |
| Риски | Пожар, взрыв, удар молнии, землетрясение, наводнение, сель, оползень, буря, ливень, просадка грунта |
| Факторы риска | Горючесть конструкций и содержимого, защита, сейсмозона, износ, удалённость пожарной части |
| Сценарий убытка | Пожар считается от самого дорогого отсека. Землетрясение считается по всей площадке. Берётся большее |
| Документы и статистика | Кадастровые документы, отчёт оценщика, сведения о сигнализации, фото. Жилой фонд по материалу стен, чрезвычайные ситуации, индексы цен |

### Класс 9. Имущество от ущерба

| Поле | Содержание |
|---|---|
| Объект | Имущество из класса 8 по рискам, не связанным с огнём и стихией |

| Дополнительные данные | Охрана, сигнализация, решётки, видеонаблюдение, состояние коммуникаций, убытки за 3 года |

| Риски | Кража со взломом, грабёж, залив водой, бой стёкол, поломка оборудования, противоправные действия |
| Факторы риска | Охрана, ценность и ликвидность содержимого, район, состояние труб |
| Сценарий убытка | Доля стоимости наибольшего помещения с поправкой на охрану |
| Документы и статистика | Договор с охраной, опись. Преступления и кражи по регионам |

| Риски | Перерыв в производстве, потеря прибыли, неисполнение контрагентом, потеря арендной платы |
| Факторы риска | Срок восстановления, зависимость от одного объекта или поставщика |
| Сценарий убытка | Ежемесячные потери, умноженные на срок восстановления |
| Документы и статистика | Отчётность, договоры. Инфляция, курс валют |

Вариант 16у, урожай сельскохозяйственных культур, с версии 1.1 анализируется по своему шаблону (ниже).

### Класс 18. Медицинское страхование (Tibbiy sugʻurta)

Формулировка акта (ПКМ № 80, прил. 6, п. 12, отрасль «Umumiy sugʻurta sohasi», 18-klass «Tibbiy sugʻurta»), дословно: «Sugʻurtalangan shaxsning sugʻurta shartnomasida koʻrsatilgan shartlarga muvofiq tibbiy yordam olishini taʼminlaydigan sugʻurta turlarining majmui, biroq 2-klass va hayotni sugʻurta qilish sohasining IV klassi boʻyicha shartnomalarni istisno qilgan holda». Перевод разработчика: совокупность видов страхования, обеспечивающих получение застрахованным медицинской помощи на условиях договора, за исключением договоров класса 2 и класса IV отрасли жизни.

| Поле | Содержание |
|---|---|
| Объект | Человек или группа людей: получение медицинской помощи на условиях договора |
| Обязательные данные | Число застрахованных, программа (пакет) медицинских услуг, лимит на человека, территория действия |
| Дополнительные данные | Возрастной состав (только агрегаты), сеть клиник, франшиза, сооплата застрахованного, период ожидания, среднее число обращений и средний счёт (экспертно), убытки за 3 года |
| Оценка стоимости | Метод 6: лимит на человека, умноженный на число людей |
| Риски | Амбулаторная помощь 35 %, стационар 30 %, экстренная помощь 12 %, лекарства 10 %, ведение беременности и роды 7 %, стоматология 6 % (оценка разработчика, не утверждено страховщиком) |
| Факторы риска | Возраст (агрегатами), состав программы, частота обращений, уровень цен клиник сети, территория; снижают — сооплата, период ожидания, франшиза |
| Сценарий убытка | Частотный, как у класса 2: PML и EML — лимит на одного человека; MFL — эпидемия: 30 % страховой суммы (экспертно), не меньше лимита на человека; ожидаемый годовой убыток (обращения × счёт × люди) — справочно |
| Документы и статистика | Программа страхования (перечень услуг и лимиты), список клиник, список застрахованных без персональных данных (число и возрастные группы). Заболеваемость острыми инфекциями дыхательных путей, обеспеченность врачами и койками, смертность |

Чем отличается от класса 2 по акту: класс 2 «Kasallikdan ehtiyot shart sugʻurta qilish» — выплата установленной денежной суммы или денежной компенсации в связи с болезнью или расстройством здоровья («sugʻurta taʼminotining belgilab qoʻyilgan pul summasi toʻlanishini yoki … pul kompensatsiyasi»); класс 18 — обеспечение получения медицинской помощи, и договоры класса 2 в него прямо не входят. Коротко: деньги — класс 2, медицинская помощь — класс 18. Отнесение конкретного продукта — решение страховщика.

Учётная группа РНП не задана: Положение 1882, п. 10 перечисляет классы 1–17, класса 18 в нём нет (класс 2 там — 1-я группа; относить ли к ней класс 18 — решение страховщика). Персональные данные застрахованных в акт и модель не попадают: возраст — только агрегатами, диагнозы и обращения конкретных людей не вводятся.

### Вариант 13з. Ответственность заёмщиков за непогашение кредитов

Вариант класса 13 (Положение 1882, п. 10: класс 13, 2-я учётная группа).

| Поле | Содержание |
|---|---|
| Объект | Гражданская ответственность заёмщика перед банком-кредитором за непогашение кредита |
| Обязательные данные | Сумма кредита, стоимость обеспечения, срок кредита, вид заёмщика |
| Дополнительные данные | Отрасль заёмщика, кредитная история по отчёту кредитного бюро (КАТМ), назначение кредита, убытки за 3 года, франшиза |
| Оценка стоимости | Метод 6 с ограничением: страхуется только необеспеченная часть и не более 50 % кредита |
| Риски | Непогашение кредита в срок 55 %, неплатёжеспособность и банкротство заёмщика 30 %, прекращение деятельности заёмщика 15 % (экспертно) |
| Факторы риска | Кредитная история (данные КАТМ), обеспечение, срок, отрасль, вид заёмщика |
| Сценарий убытка | Полная страховая сумма. Проверка: сумма не больше min(кредит − обеспечение; 50 % кредита). Накопление по одному банку и отрасли |
| Документы и статистика | Кредитный договор и график, договор залога, отчёт кредитного бюро, отчётность заёмщика-юрлица. Ликвидации предприятий, мошенничества, кредиты банков |

Чем отличается от класса 14: в классе 14 страхуется риск кредитора — убыток банка от неплатежа должника; в варианте 13з — гражданская ответственность самого заёмщика перед банком. Страхователь и плательщик премии — банк-кредитор (правило компании).

### Вариант 16у. Урожай сельскохозяйственных культур

Вариант класса 16 (Положение 1882, п. 10: класс 16, 4-я учётная группа). Объект и перечень рисков — по Закону «О страховании сельскохозяйственных рисков» ЗРУ-1056 от 14.04.2025, ст. 16 и ст. 5.

| Поле | Содержание |
|---|---|
| Объект | Посевы сельхозкультуры (будущий урожай): культура, площадь, регион, поле |
| Обязательные данные | Культура, площадь посевов в гектарах, средняя урожайность за 5 лет (ц/га), цена единицы продукции (сум за центнер) |
| Дополнительные данные | Поле или кадастровый номер участка, орошение, агротехника, сорт, урожайность по годам, убытки за 3 года, франшиза |
| Оценка стоимости | Страховая стоимость = площадь × средняя урожайность за 5 лет × цена. Пример: 100 га × 30 ц/га × 400 000 сум = 1,2 млрд сум |
| Риски | Засуха 30 % (катастрофический), град 15 %, заморозки 15 % (катастрофический), сель и наводнение 10 % (катастрофический), ураган 5 %, болезни и вредители 15 %, пожар 5 %, дикие животные 2 %, действия третьих лиц 3 % (экспертно) |
| Факторы риска | Орошение, агротехника, сорт, история урожайности, регион |
| Сценарий убытка | База — меньшее из страховой суммы и стоимости урожая. PML: частичная потеря урожая на части площади (база × 30 % площади × 50 % потери). EML: гибель на значительной площади (база × 60 %). MFL: полная гибель на всей площади. Доли экспертные |
| Документы и статистика | Сведения о посевах, справка об урожайности за 5 лет, право пользования землёй, технологическая карта и орошение. Изменчивость сбора зерна и пшеницы, валовой сбор, продукция растениеводства, чрезвычайные ситуации |

Страховая сумма выше стоимости урожая недопустима (ГК, ст. 938), ниже — пропорциональная выплата (ГК, ст. 936).

## А.4. Порядок настройки шаблонов

1. Шаблоны хранятся в справочнике, а не в программе. Администратор меняет поля, риски и доли без участия разработчика.
2. Страховщик вправе убрать классы, по которым нет лицензии, и добавить свои продукты внутри класса.
3. Продукт из нескольких классов анализируется по каждому классу отдельно, премии складываются.
4. Все доли ущерба, веса и пороги помечены «не калибровано», пока страховщик не дал статистику убытков. Доли рисков в шаблонах и в справочнике рисков классов 8 и 9 — оценка разработчика, не утверждено страховщиком.

## А.5. Состав

20 шаблонов: 18 классов общего страхования и варианты 13з, 16у (версия 1.3 от 01.10.2026).

- 18 классов общего страхования — 1–18 (класс 18 «Tibbiy sugʻurta», медицинское страхование, добавлен в версии 1.2);
- 2 варианта со своими шаблонами — 13з (ответственность заёмщиков за непогашение кредитов) и 16у (урожай сельскохозяйственных культур); раньше они анализировались по шаблонам 14 и 16, ссылка осталась только запасным путём для старого файла шаблонов.

Классов страхования жизни в шаблонах нет (шаблоны отрасли жизни были добавлены по ошибке и удалены 01.10.2026). Справочник классов базы не меняется: если строки классов жизни там окажутся, система их не показывает и акт по ним не формирует.

Шаблоны заведены в справочник class_templates (docs/act_class_templates.json, версия 1.3.0 от 01.10.2026); класс 18 — в справочник классов с отраслью «общее», учётной группы у него нет (в Положении 1882, п. 10 класса 18 нет). Продуктов классов 18 и 16у у страховщика пока нет: акт формируется по шаблону, ставка не определена. Если администратор уже правил шаблон класса, новая версия файла его правку не заменяет — она попадает в историю версий с пометкой «доступна новая версия шаблона из поставки». Сводка по всем шаблонам — docs/Шаблоны классов — сводка.md (скрипт tools/templates_summary.py).
