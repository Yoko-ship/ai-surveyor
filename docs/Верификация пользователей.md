# Как люди проходят проверку в системе

Для руководителя. Техническая реализация — `app/auth.py`, страница входа — `/login`.

## Кто и как получает доступ

1. **Заявка.** Сотрудник открывает `/login`, вкладка «Подать заявку»: ФИО, телефон, логин, пароль, филиал, роль.
   Для роли «агент» обязателен **ID агента из реестра** — по Положению № 3845 агент без включения в реестр
   страховщика работать не может, и система заявку без ID не принимает.
2. **Сверка.** Администратор видит список заявок, сверяет с реестром агентов компании (ФИО, филиал, ID)
   и нажимает «Подтвердить» или «Отклонить». Отклонённая заявка удаляется. Оба действия пишутся в журнал.
3. **Вход.** Логин и пароль. Если у пользователя привязан Telegram — второй шаг: код из шести цифр,
   действует 5 минут. Пока бот не подключён, второй шаг отключён.
4. **Сессия** живёт 12 часов и продлевается при работе; выход — кнопкой.

Первый администратор создаётся при первой регистрации, когда база пользователей пуста, — это тоже фиксируется в журнале.

## Кто что видит

| Роль | Доступ |
|---|---|
| Агент | новый расчёт, свои запросы, предложение клиенту |
| Андеррайтер | все запросы, решения по ним, портфельный аудит |
| Актуарий | калибровка, ёмкость и удержание, версии тарифов |
| Администратор | всё, включая заявки пользователей, справочники и журнал |

## Как отключается уволенный агент

Администратор ставит статус «заблокирован» — вход закрывается сразу, действующие сессии обрываются.
Если агент исключён из реестра компании, вход невозможен даже с верным паролем.

## Что пишется в журнал

Заявка, подтверждение и отклонение, вход, неудачные попытки входа, блокировка, выход.

## Что нужно для кода в Telegram

Бот Telegram и его токен (переменная `TG_BOT_TOKEN` на сервере). Пользователь один раз пишет боту «/start» —
после этого коды приходят ему в чат. Без бота вход работает по паролю.

## Как хранятся пароли

Пароль в базе не хранится — только его хэш (PBKDF2-SHA256, 200 000 итераций, своя соль на каждого пользователя).
Восстановить пароль из базы нельзя; сменить — может администратор.
