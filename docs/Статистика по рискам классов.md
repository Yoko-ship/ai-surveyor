# Статистика органа статистики по рискам всех классов страхования

Задача заказчика от 22.09.2026 (задача 162 в очереди): «сделать так, чтобы парсинг был и с Агентства статистики,
относящийся к рискам по всем классам страхования, которые тоже должны учитываться при анализе рисков».

Проверено 22.09.2026: каталог stat.uz (`docs/stat_uz_catalog.json`, 1 189 наборов) и поиск по порталу
data.egov.uz. Каждый набор из таблицы ниже скачан и разобран, а не взят по названию.
Полная таблица «класс → набор» (id, период, регионы, единица, ссылка, ограничения) —
`docs/Статистика по рискам классов.csv`.

## Коротко

- В реестр `app/stat_sources.py` добавлено **36 наборов** (всего теперь 52). У каждого набора есть поле `class_codes`.
  Загружены в рабочую базу один раз: **4 502 строки** в `stat_series`. У каждой строки есть ссылка на страницу набора.
- Суточное обновление подхватит новые наборы **после перезапуска сервера**. Сейчас в памяти работающего сервера старый реестр из 16 наборов.
- Показатели риска по классу и региону считает `app/risk_stats.py`, проверить можно через `GET /stat/risk-indicators?class_code=&region=`.
- В анализе риска появилась шестая составляющая уровня риска, «Внешняя статистика региона». Вес по умолчанию 0,10 (потом нормируется вместе с остальными), `calibrated = 0`.
  В ответе `POST /analytics/risk` есть новый блок `external_stats`. Премии и сценарии не меняются.
- В балл входят только показатели, у которых есть разрез по регионам. Если по классу таких показателей нет или регион не задан, составляющая не учитывается, а в ответе объясняется почему.

## Чего в открытых данных нет (искали и не нашли)

- **Пожары и ущерб от пожаров по регионам.** Единственный набор про пожары на data.egov.uz пуст. У МЧС есть только два квартала ЧС, без регионов и без сумм ущерба. Перечня землетрясений тоже нет, поэтому сейсмозона по-прежнему вводится вручную.
- **Угоны ТС и парк ТС по регионам.** Кражи публикуются все вместе. Набор МВД — это сервис проверки одной машины.
- **ДТП МВД по регионам** (`6107bba6…`): в наборе у 2026 года не подписано, сколько месяцев он охватывает. Период неясен, поэтому набор не загружался. Взяты ряды органа статистики (2014–2024).
- **Аварии на железной дороге, в авиации, на воде.** Есть только объёмы перевозок. Морского и речного транспорта в статистике нет вообще.
- **Судебные дела (класс 17).** Набор Верховного суда «Данные о судебных решениях» пуст.
- **Просроченные и проблемные кредиты.** Набор ЦБ пуст. Просроченная дебиторская и кредиторская задолженность предприятий по регионам лежит в наборах, которые либо пусты (`694ab7a1…`, `694ab7cd…`), либо без указания периода (`6108d2db…`).
- **Банкротства отдельно от ликвидаций.** Есть только перечень госпредприятий-банкротов, это список, а не статистика.
- **Урожайность и посевные площади по годам.** Наборы урожайности на data.egov.uz без указания года, посевные площади хлопчатника пусты. Поэтому для 16у взят валовой сбор.
- **Общая заболеваемость по регионам по годам.** Набор Минздрава без года.
- **Производственный травматизм по регионам.** Есть только республика и отрасли, и только за 2020 год.

## Как учитывается в уровне риска

Для каждого показателя класса, у которого есть разрез по регионам:

    отношение = показатель региона / тот же показатель республики за тот же период
        (для счётных — на 1 000 жителей: случаи за год / население на начало года, тыс. чел.;
         для коэффициентов — как есть; для урожая — изменчивость; для жилфонда — доля, %)
    балл показателя = 0, если отношение ≤ 0,5;  100, если ≥ 1,5;  между — по прямой
                      (уровень республики, отношение 1,0 → 50 баллов)
    балл составляющей = среднее баллов показателей
    уровень риска = Σ (балл × вес) / Σ весов применимых составляющих
        веса по умолчанию: ставка 0,25; MFL 0,25; убытки 0,20; сумма к стоимости 0,10; сейсмика 0,20;
        внешняя статистика 0,10

Пороги хранятся в `risk_thresholds` (правит админ: `PUT /analytics/risk/thresholds`):
`external_ratio` = [0,5; 1,5], `external_volatility_years` = 10, вес `weights.external_stats` = 0,10.
Шкала экспертная, `calibrated = 0`: калибровать её не на чем, пока нет убытков компании по регионам.

В примере 3 спецтехника в Навоийской области попадает в регион с частотой ДТП ниже республиканской. Балл снизился на 2,9 и перешёл границу 60.

менялись бы при каждом суточном обновлении stat.uz. Со статистикой те же примеры проверяет
`tests/test_risk_stats.py` на зафиксированных рядах: склад 0,0 → 7,2, производство 57,8 → 55,6.

## Оговорки к показателям

- **Счётные показатели на 1 000 жителей.** Случаи за год делятся на население на **начало** того же года. Если населения за этот год нет, берётся последнее более раннее, и об этом есть пометка.
- **Преступления и кражи.** Считаются зарегистрированные, а не раскрытые. В городе Ташкенте уровень в 2,4 раза выше республиканского, частично это эффект столицы (приезжие, учёт). Ряд краж с 2024 года вырос втрое (14 851 → 48 375), вероятно, из-за изменения учёта.
- **ДТП.** Все ДТП по учёту органа статистики, а не страховые случаи. Сумма регионов за 2024 год равна республике (9 364).
- **Заболеваемость ОРИ** в балл не входит: около 73% всех случаев республики приходится на город Ташкент, так что разброс между регионами отражает учёт обращений, а не частоту болезни.
- **Изменчивость сбора зерна.** Это валовой сбор, а не урожайность: колебания могут идти и от изменения посевных площадей.
- **Ликвидации предприятий.** Ликвидации по любой причине, а не только банкротства. Полный год в наборе один (2024), поэтому тренда нет.
- **Курс ЦБ.** Набор отдаёт только один день, история копится с каждым суточным обновлением.
- **Показатели только по республике** (ж/д, авиация, травматизм, мошенничество, инфляция) показываются для справки с пометкой «республика — у набора нет разреза по регионам» и в балл не входят.
