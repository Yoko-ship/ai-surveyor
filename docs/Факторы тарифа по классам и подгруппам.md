# Факторы, повышающие и понижающие тариф, по классам и подгруппам

Версия от 02.10.2026. Документ для андеррайтеров и для настройки системы.

Как читать. По каждому классу: подгруппы объектов, затем факторы. Знак «+» — тариф выше, «−» — ниже. Величина влияния здесь не указана: размер поправок утверждает актуарий страховщика, система помечает их «не калибровано», пока нет статистики убытков компании.

## Общие факторы для всех классов

| Фактор | Повышает (+) | Понижает (−) |
|---|---|---|
| История убытков клиента | Убытки за 3–5 лет, особенно частые мелкие; крупный убыток за последний год | Безубыточная история 3 года и больше |
| Документы | Нет документов на объект, расхождения между документами, осмотр не проводился | Полный комплект, осмотр проведён, фото со всех ракурсов |
| Страховая сумма к стоимости | Сумма выше стоимости; сумма ниже 70 % стоимости (спорная пропорция при выплате) | Сумма равна стоимости по отчёту оценщика |
| Срок | Многолетний договор без ежегодного пересмотра условий | Год или ежегодный пересмотр |
| Франшиза | Отказ от франшизы при частых мелких убытках | Безусловная франшиза, соразмерная частоте убытков |
| Клиент | Новый клиент без истории; частая смена страховщиков | Клиент с портфелем в компании и хорошей историей |
| Оплата | Рассрочка с просрочками в прошлом | Единовременная оплата |
| Накопление | Несколько объектов клиента в одном месте или на одном маршруте | Объекты разнесены |

## Класс 3. Наземный транспорт

### Подгруппы по типу транспорта

| Подгруппа | Что повышает | Что понижает |
|---|---|---|
| Легковые автомобили | Такси и аренда, спортивные и премиальные модели, частая смена водителей | Личное использование, семейный автомобиль, один водитель |
| Грузовые автомобили | Междугородние и международные перевозки, опасные грузы, самосвалы на карьерах | Внутригородская развозка, собственный гараж |
| Автобусы и микроавтобусы | Маршрутные и туристические перевозки, ночные рейсы, горные дороги | Служебный транспорт по постоянному маршруту |
| Прицепы и полуприцепы | Цистерны, рефрижераторы, тяжеловозы | Бортовые прицепы, стоянка на базе |
| Спецтехника колёсная: краны, погрузчики, бетононасосы | Работа на стройке, у ЛЭП, на открытых площадках, передача в аренду | Работа на огороженной территории предприятия, обученный машинист |
| Спецтехника гусеничная: экскаваторы, бульдозеры | Карьеры, шахты, перевозка между объектами на трале | Один объект, площадка под охраной |
| Сельхозтехника: тракторы, комбайны | Сезонная работа в поле, хранение под открытым небом | Хранение в закрытом ангаре, обслуживание в сезон |
| Мотоциклы и мопеды | Высокая частота ДТП и краж, молодые водители | Хранение в гараже, сезонное использование |

| Фактор | Повышает | Понижает |
|---|---|---|

| Стёкла и оптика | Дорогая оптика, панорамные стёкла | Обычные |
| Повреждения на осмотре | Есть неустранённые повреждения | Нет |

## Класс 4. Железнодорожный подвижной состав

| Подгруппа | Повышает | Понижает |
|---|---|---|
| Локомотивы | Возраст более 25 лет, маневровая работа на станциях | Новые, магистральные с плановым ТО |
| Пассажирские вагоны | Международные маршруты, устаревшие тормозные системы | Внутренние маршруты, недавний капремонт |
| Грузовые вагоны и платформы | Перевозка угля и руды, частая погрузка кранами | Контейнерные платформы |
| Цистерны | Опасные грузы: нефть, газ, химия; просроченное освидетельствование котла | Пищевые грузы, свежее освидетельствование |

Общие для класса: состояние путей на маршруте, сроки плановых ремонтов, опасные грузы, перегруз.

## Класс 5. Авиация

| Подгруппа | Повышает | Понижает |
|---|---|---|
| Пассажирские самолёты | Возраст борта, малый налёт экипажа, сложные аэродромы (горы, короткие полосы) | Молодой парк, обслуживание у производителя |
| Грузовые самолёты | Ночные рейсы, опасные грузы, нерегулярные аэродромы | Регулярные маршруты |

| Малая и частная авиация | Любительская эксплуатация, редкие полёты | Профессиональный экипаж |
| Беспилотники | Полёты над людьми и объектами, ручное управление | Автоматические маршруты, страхование ответственности оператора |

Общие: сертификат лётной годности, налёт часов, квалификация экипажа, тип аэродромов, орнитологическая обстановка, ангарное хранение.

## Класс 9. Имущество от ущерба: кража, залив, бой стёкол, поломки

| Подгруппа | Повышает | Понижает |

## Класс 10. Автогражданская ответственность

| Подгруппа | Повышает | Понижает |
|---|---|---|
| Легковые | Такси, аренда, молодые водители, нарушения | Личное использование, стаж |
| Грузовые и автобусы | Международные перевозки, пассажиры, опасные грузы | Городские маршруты |
| Спецтехника | Работа на дорогах общего пользования | Работа на закрытой территории |

Прочие: мощность, территория использования, число водителей и стаж, история нарушений, лимит ответственности. Обязательный вид считается по нормативному тарифу — факторы влияют только на добровольное расширение.

## Как это должно работать в системе

1. Для каждого класса в шаблоне заводится список подгрупп и факторов из этого документа.
2. У каждого фактора — коэффициент: больше 1 повышает, меньше 1 понижает. Пока коэффициенты экспертные, они помечены «не калибровано».
3. Ставка акта = ставка продукта × произведение коэффициентов по заполненным факторам, не ниже минимальной ставки.
4. Незаполненный фактор не меняет ставку, но акт перечисляет его в «уточнить».
5. Актуарий страховщика утверждает коэффициенты в админке; после загрузки убытков за 3–5 лет система пересчитывает их по статистике.
