# Техническое задание: мини-приложение «ИИ-сюрвейер»

Версия 1.0 от 28.09.2026. Документ описывает только мини-приложение для сотрудников. Админка описана в общем ТЗ.

## 1. Назначение

Мини-приложение помогает сотруднику страховой организации за несколько минут оценить риск объекта и получить обоснованную ставку. Приложение только анализирует и советует. Решение о принятии риска принимает человек.

Приложение даёт сотруднику:

- оценку стоимости объекта;
- перечень рисков и уровень риска;
- ставку и премию с расшифровкой;
- вывод по франшизе: нужна она или нет;
- список документов, которых не хватает;
- ответы на вопросы по страхованию и закону.

## 2. Где работает

| Платформа | Требование |
|---|---|
| Telegram | Открывается кнопкой бота как мини-приложение |
| Сайт | Открывается по ссылке в браузере на телефоне и компьютере |
| Экран | Один интерфейс для телефона и компьютера, ширина от 390 пикселей |

## 3. Пользователи и доступ

1. Приложение открыто для всех сотрудников. Регистрации и заявок на доступ нет.
2. Профиль необязателен. Вход в профиль одним нажатием через Telegram или Google. Оба способа привязываются к одному профилю.
3. В профиле сотрудник может сменить имя.
4. Доступ в админку запрашивается кнопкой в приложении. Запрос приходит только владельцу системы в Telegram. Владелец подтверждает или отклоняет.
5. Администратор может выйти из админки в обычный режим пользователя.
6. Гость без профиля ограничен: 60 анализов, 30 загрузок и 200 вопросов в час с одного устройства.

## 4. Состав приложения

| № | Раздел | Что делает |
|---|---|---|
| 1 | ИИ-сюрвейер | Диалог: документы, данные объекта, анализ риска, ставка, вывод по франшизе |
| 2 | Калькулятор | Быстрый расчёт премии по любому продукту |
| 3 | Обязательные виды | Расчёт премии по нормативному тарифу, для Узбекистана ОСГОР |
| 4 | ИИ специалист | Ответы на вопросы по страхованию и закону |
| 5 | Профиль | Имя, способы входа, язык, запрос доступа в админку |

Обложки и заставки нет. Приложение сразу открывается на разделе «ИИ-сюрвейер».

## 5. Раздел «ИИ-сюрвейер»

### 5.1. Порядок работы

| Шаг | Что делает сотрудник | Что делает приложение |
|---|---|---|
| 1 | Загружает документы | Разбирает файлы, сообщает, каких документов не хватает |
| 2 | Заполняет четыре поля | Подставляет значения из договора с пометкой «проверьте» |
| 3 | По желанию добавляет данные | Незаполненное берёт по умолчанию и помечает это |
| 4 | Нажимает «Считаем» | Оценивает стоимость, выявляет риски, считает ставку |
| 5 | Читает результат | Показывает результат и отвечает на уточняющие вопросы |

### 5.2. Загрузка файлов

1. Форматы: PDF, DOCX, XLSX, JPG, PNG.
2. Способы: перетаскивание в любое место экрана, вставка из буфера, кнопка-скрепка.
3. До 10 файлов, до 15 МБ каждый.
4. Принимается один общий PDF со всеми документами. Приложение сообщает, какие документы из перечня продукта в нём есть и каких нет.
5. Документы переводятся во внутренний структурированный вид. Из договора извлекаются страховая сумма, стоимость, срок, адрес и регион, тип объекта, конструкция.
6. Из техпаспорта и кадастровых документов поля объекта заполняются автоматически. Данные владельца не сохраняются.

### 5.3. Данные объекта

1. Обязательных полей четыре: продукт или класс, страховая сумма, стоимость объекта, регион.
2. Остальные поля сотрудник выбирает сам из списка.
3. Приложение запоминает последний договор на 7 дней и спрашивает: «по прошлому договору или по новому».
4. В перечень документов и вопросов не входят пункты оформления договора: заявление клиента, факт оплаты премии, факт информирования клиента.

### 5.4. Оценка стоимости объекта

1. Приложение само оценивает стоимость и сравнивает её с заявленной.
2. Методы по порядку: рынок, запрос дилеру, стоимость минус износ, отчёт оценщика, балансовая стоимость, лимит по договору.
3. Объявления берутся не старше шести месяцев. Для транспорта учитывается пробег.
4. Износ по умолчанию: здания 3 % в год, транспорт 20 %, компьютеры 20 %, мебель и оборудование 15 %, прочее 15 %.
5. Если оценка отличается от заявленной больше чем на 15 %, показывается уточнённая стоимость с объяснением.
6. Транспорт и спецтехника различаются по регистрационному документу.

### 5.5. Результат анализа

| № | Что показывается |
|---|---|
| 1 | Уровень риска по пяти ступеням и балл от 0 до 100 с составляющими |
| 2 | Ставка применённая, техническая, минимальная и рыночная |
| 3 | Премия |
| 4 | Сценарии убытка PML, EML, MFL и лимит собственного удержания |
| 5 | Риски и факторы, которые повышают и снижают ставку |
| 6 | Статистика по рискам региона |
| 7 | Вывод по франшизе |
| 8 | Варианты тарифа с изменением премии |
| 9 | Совет по тарифу с пояснением |
| 10 | Список недостающих документов |

### 5.6. Франшиза

1. Франшиза не обязательна. По умолчанию приложение её не предлагает.
2. Франшиза рекомендуется только при основании:
   - два и более убытка за три года, и больше половины из них мелкие;
   - уровень риска «Высокий» или «Критический»;
   - один риск даёт большую часть ставки, и по нему есть неблагоприятный фактор;
   - клиент просит снизить премию.
3. Если оснований нет, приложение пишет «Франшиза не требуется» и объясняет почему.
4. Рекомендация содержит вид франшизы, размер, риск, изменение премии и основание.
5. Вместо франшизы приложение предлагает другое: мероприятия, исключение риска, приведение суммы к стоимости.
6. Сотрудник может посчитать вариант с любой франшизой сам.
7. По обязательным видам франшиза не применяется.

### 5.7. Классы и комплексные продукты

1. Анализ работает по всем классам страхования из справочника.
2. На каждый класс заведён один шаблон анализа. Шаблонов 17, они приведены в приложении А общего ТЗ.
3. Комплексный продукт разбирается по частям. Каждая часть анализируется по шаблону своего класса.
4. Ставка проверяется по каждому классу отдельно. Премии частей складываются.
5. Уровень риска по договору определяется по самой опасной части.

## 6. Раздел «Калькулятор»

1. Поля: продукт, страховая сумма, срок, до трёх факторов.
2. Формула: базовая нетто-ставка × коэффициенты + рисковая надбавка, затем деление на (1 − нагрузка).
3. Итог сравнивается с минимальным тарифом.
4. Показывается расшифровка расчёта по шагам.

## 7. Раздел «Обязательные виды»

1. Премия считается строго по формуле нормативного акта. Скидки, надбавки и франшиза не применяются.
2. ОСГОР: премия = годовой фонд оплаты труда × 0,1 % × коэффициент вида деятельности.
3. Вид деятельности выбирается поиском по названию или коду ОКЭД.
4. Минимальная премия привязана к базовой расчётной величине. Её значение вводит администратор.
5. Каждый шаг расчёта сопровождается ссылкой на пункт акта.

## 8. Раздел «ИИ специалист»

1. Отвечает на языке вопроса: русский, узбекский, английский.
2. Источники ответа по порядку: готовые ответы, тексты актов в базе, поиск на lex.uz, языковая модель.
3. Если в базе нормы нет, специалист ищет действующий акт на lex.uz и отвечает цитатой со ссылкой. Найденный акт сохраняется в базу.
4. Каждая норма приводится дословной цитатой. Под цитатой стоит ссылка «Читать в источнике».
5. Официальным считается узбекский текст. Русский и английский тексты помечаются как неофициальный перевод.
6. Если акт изменился, специалист предупреждает об этом и даёт ссылку на действующую редакцию.
7. Если нормы нет, специалист пишет об этом прямо.
8. Запрещено: придумывать нормы и реквизиты актов, обещать выплату, давать ставку ниже минимальной, отказывать в страховании от своего имени.

## 9. Интерфейс

| Требование | Значение |
|---|---|
| Меню | Слева, с подписями разделов |
| Переключатель языка | В левом меню, не перекрывает содержимое |
| Кнопки | Единый набор: основная, вторичная, подтверждение, отмена. Текст читается на любой теме Telegram |
| Контраст текста | Не ниже 4,5 к 1 |
| Таблицы и колонки | Компактные, без горизонтальной прокрутки |
| Визуальный язык | Привычный для Telegram |
| Заполнение | Минимум полей, выбор из списков, кнопки быстрых значений |
| Служебные слова | В тексте для пользователя нет кодов и технических пометок |

## 10. Языки

1. Языки интерфейса: русский, узбекский, английский.
2. Переключение мгновенное, без перезагрузки.
3. Перерисовывается весь экран, включая ответы ИИ.
4. Введённые данные при переключении сохраняются.

## 11. Данные и безопасность

1. Персональные данные в языковую модель не передаются. Перед отправкой ФИО, паспорт, идентификационный номер, телефон и почта заменяются метками.
2. В запросы к внешним сайтам не попадают фамилии, адреса и названия компаний.
3. Персональные данные не пишутся в журналы.
4. Загруженные файлы хранятся 24 часа. Диалог хранится 7 дней.
5. Защита внешних сайтов не обходится.
6. У каждой внешней цифры и цитаты есть ссылка на источник.
7. Рабочие данные размещаются на сервере в стране страховщика, если этого требует закон. На тестовый зарубежный сервер реальные договоры не загружаются.

## 12. Скорость и надёжность

| Требование | Значение |
|---|---|
| Расчёт ставки | до 0,3 секунды |
| Ответ специалиста из базы | до 0,3 секунды |
| Ответ с поиском на lex.uz | до 15 секунд |
| Ответ языковой модели | до 10 секунд, затем ответ по правилам |
| Первый экран на телефоне | до 700 КБ |
| Работа без языковой модели | Расчёты и анализ доступны, меняется только текст пояснений |
| Недоступность внешнего сайта | Приложение сообщает об этом и отвечает по базе |

## 14. Чего в приложении нет

1. Регистрации и заявок на доступ к приложению.
2. Обложки и заставки.
3. Разделов «Запросы», «Соглашения», «Заявки», «Ждут меня».
4. Согласования запросов несколькими лицами и сообщений бота о согласовании.
5. Интеграции с государственными информационными системами и с учётной системой страховщика.
6. Расчётов по страхованию жизни.
7. Видео в интерфейсе.

## 15. Критерии приёмки

Приложение принимается, если выполнено всё перечисленное.

1. Приложение открывается в Telegram и в браузере сразу на разделе «ИИ-сюрвейер», без регистрации.
2. Анализ по четырём полям проходит по каждому классу из справочника.
3. Десять контрольных расчётов совпадают с ручным расчётом актуария до 1 сума.
4. Договор в PDF и DOCX загружается, сумма и стоимость подставляются верно в 9 случаях из 10.
5. При отсутствии оснований приложение пишет «Франшиза не требуется».
6. Специалист отвечает на 20 контрольных вопросов, каждая цитата находится в тексте акта дословно.
7. На вопрос без нормы специалист отвечает «нормы нет».
8. Переключение трёх языков не оставляет текста на другом языке.
9. На экране шириной 390 пикселей нет горизонтальной прокрутки, все кнопки читаются.
10. Персональные данные отсутствуют в журналах, в запросах к языковой модели и к внешним сайтам.
11. Запрос доступа в админку приходит только владельцу.

## 16. Ограничения

1. Приложение советует, решение принимает сотрудник.
2. Распознавание сканов и фото без текстового слоя не гарантируется.
3. Экспертные коэффициенты и пороги помечены «не калибровано», пока страховщик не дал статистику убытков.
4. Часть актов на lex.uz есть только на узбекском языке. По ним на русском даётся ссылка, а не цитата.
5. Рыночная стоимость недвижимости по объявлениям недоступна, пока площадки закрыты от автоматических запросов.
