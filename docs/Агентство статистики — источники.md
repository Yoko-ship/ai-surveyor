Проверено 20.09.2026 по самим сайтам. Ниже — только то, что реально прочитано на страницах и в нормативном акте.

## Что написано на data.egov.uz

В подвале каждой страницы портала:

- «При использовании материалов сайта полностью или частично, ссылка на сайт обязательна»;
- `<a rel="license" href="http://creativecommons.org/licenses/by-sa/4.0/">Лицензия: Creative Commons Attribution-ShareAlike 4.0</a>` — то есть CC BY-SA 4.0 (указание авторства + производное распространяется на тех же условиях);
- сертификат Open Data Institute уровня Gold (`certificates.theodi.org/en/datasets/225526/certificate`).

Страница «Условия использования» — https://data.egov.uz/rus/copyrights (текст подгружается запросом `https://data.egov.uz/apiClient/Main/GetNewsId?slug=portal-haqida-1`, в браузере виден как есть):

> «Пользователь вправе использовать (в том числе повторно) открытые данные свободно, бессрочно, безвозмездно и без ограничения территории использования, в том числе имеет право копировать, публиковать, распространять, видоизменять открытые данные и объединять их с другой информацией, **использовать открытые данные в коммерческих целях**, использовать для создания программных продуктов и приложений.»

Там же — политика конфиденциальности портала: он логирует IP, провайдера, браузер, дату и время, посещённые страницы и реферера. Для нас это значит, что массовые обращения с нашего сервера видны оператору.

`https://data.egov.uz/robots.txt`: запрещены только `/panel/*`, `/operator/*`, `/author/*`; указан sitemap. Частоту обращений и объёмы портал не ограничивает — явных лимитов в robots.txt нет.

Доступ: открытые методы (`/apiClient/...`) отдают JSON без ключа. Партнёрский раздел (`/apiPartner/...`) требует входа через OneID (`auth.egov.uz`) — то есть регистрации.

## Что написано на stat.uz

Подвал сайта (на 20.09.2026 владелец указан как **Национальный комитет Республики Узбекистан по статистике**, не «Агентство статистики»):

> «2026 год. Национальный комитет Республики Узбекистан по статистике. При использовании информации, **ссылка на www.stat.uz обязательна**. Все материалы сайта доступны по лицензии: Creative Commons Attribution 4.0 International».

Расхождение в самом подвале: текст и значок — CC BY 4.0 (`creativecommons.org/licenses/by/4.0/`), а соседняя ссылка ведёт на CC BY-SA 4.0 (`creativecommons.org/licenses/by-sa/4.0/`). Пока считаем обязательной более строгую версию (BY-SA).

Отдельного документа «Условия использования» на stat.uz нет. Есть только «Условия конфиденциальности» — PDF на узбекском (https://stat.uz/img/news/maxfiylik_p47303.pdf): он про персональные данные пользователей личного кабинета (Ф.И.О., IP, телефон, логин из id.egov.uz) и автоматическую выгрузку данных никак не регулирует.

`https://stat.uz/robots.txt` — стандартный файл Joomla: закрыты `/administrator/`, `/cache/`, `/components/`, `/libraries/`, `/modules/`, `/plugins/`, `/tmp/` и т. п. Ограничений по частоте нет.

`api.stat.uz` — корень домена отдаёт страницу «Интерактивные услуги» stat.uz; `/api/v1`, `/docs`, `/swagger` возвращают «Not Found». Публичного описания API и правил доступа к нему на домене не опубликовано.

## Норма Республики Узбекистан

Отдельного закона «Об открытых данных» в РУз не обнаружено. Сфера регулируется **постановлением Кабинета Министров № 808 от 23.12.2020 «О мерах по дальнейшему развитию сектора открытых данных в Республике Узбекистан»** (ред. ПКМ № 153 от 04.04.2022, изменения от 07.10.2025) — текст скачан: `library/01_Законодательство/01_Законы/ПКМ о развитии сектора открытых данных.txt`, источник https://lex.uz/ru/docs/5182703.

## Что это значит для нас

1. **Ссылка обязательна у каждой записи.** Для каждого показателя храним и показываем источник: «data.egov.uz» (или «www.stat.uz»), название набора, дату выгрузки. Это требование и сайтов, и п. 39 Положения (ПКМ № 808).
2. **Лицензия CC BY-SA 4.0 с портала — «заразная».** Если мы публикуем таблицу или график, построенные на данных портала, указываем авторство и не закрываем сам производный набор более строгими условиями. Внутренние расчёты (ставка, коэффициенты) — наш продукт, лицензией не затронуты; вопрос возникает только при публикации самих данных.
3. **Не выдавать за свои.** Никаких «данные INSON» под цифрами Комитета по статистике; в отчётах и на странице «Динамика рынка» источник подписывается явно.
4. **Не ломать защиту и не создавать нагрузку.** Тянем только открытые разделы (robots.txt портала закрывает `/panel/`, `/operator/`, `/author/` — туда не ходим), обходим страницы редко и последовательно, представляемся в User-Agent, кэшируем ответы. Лимитов не объявлено, но портал логирует IP и обращения.
5. **Коммерческое использование через API — отдельный разговор с оператором.** По п. 8 и п. 40 Положения бесплатным объявлено использование «в личных интересах», а электронное взаимодействие через API для коммерческой и хозяйственной деятельности из этой бесплатности исключено и оформляется договором. Мы — коммерческая компания, значит: ручное и разовое скачивание открытых наборов рисков не несёт, а постоянную автоматическую тягу через API лучше закрыть письмом/договором с оператором портала (opendata@egov.uz). Поставлено вопросом № 46 в `docs/Открытые вопросы.md`.
6. **Персональных данных в наборах быть не должно.** Если в выгрузке окажутся сведения о конкретных людях — не загружаем и сообщаем оператору; наши обязанности по ЗРУ-547 от этого не отменяются.

## Расхождения

- stat.uz: в одном и том же подвале заявлены и CC BY 4.0 (текст и значок), и CC BY-SA 4.0 (ссылка). Какая лицензия действительно применяется — из сайта не следует.
- Название владельца stat.uz в подвале — «Национальный комитет Республики Узбекистан по статистике», тогда как в наших заметках и в ПКМ № 808 фигурирует Государственный комитет / Агентство статистики. Переименование по документам не подтверждено — норму по этому поводу не писали.
- Условия использования на data.egov.uz (свободно, бессрочно, безвозмездно, в том числе в коммерческих целях) прямо не оговаривают исключение п. 8 Положения про API для коммерческой деятельности. Сайт и акт расходятся; сами их не примиряем.
