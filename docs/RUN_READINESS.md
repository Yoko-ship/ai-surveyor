# Готовность к запуску — 05.10.2026

## Текущее состояние

Локальный проект подготовлен и запущен после модульного рефакторинга.
Мини-приложение: http://127.0.0.1:8000/tg; расчёт: `/ui`; вход: `/login`;
состояние: `/health`; описание API: `/docs`.

Используются Python 3.12.10 и `sandbox/.venv`. Зависимости соответствуют
`requirements.txt`; `pip check` не находит конфликтов. Node доступен для тестов JavaScript.
Новые пакеты в ходе архитектурного рефакторинга не устанавливались.

Сервер слушает только `127.0.0.1`, один процесс Uvicorn. Включены
`SURVEYOR_DEV=1`, `SURVEYOR_NO_BACKGROUND=1`, `LLM_PROVIDER=none`, `TG_POLLING=0`,
`LEX_LIVE=0`, `DEMO_SEED=0`. Фоновые внешние обновления выключены для локальной проверки.
Для остановки запущенного в терминале сервера — Ctrl+C. Занятый этим сервером порт
не требует запуска второго экземпляра.

### Настройки запуска

Инструкции первой установки и запуска: [README](../README.md).
Архитектура и ограничения: [ARCHITECTURE](ARCHITECTURE.md).

- `run.bat` проверяет окружение, создаёт базу только при отсутствии и запускает сервер
  одним интерпретатором. Пакетный файл проверен по коду; реальный запуск проверен через Uvicorn.
- `app.main:app` остаётся совместимой точкой запуска, сборка находится в `app/application.py`.
- Настройки процесса: окружение → `.env` → `.secrets.env`. Некорректные флаги отклоняются.
  Настройки подключений через `llm.get`: база → окружение/файлы → значение по умолчанию.
- `STORAGE_DIR` задаёт каталог SQLite и загрузок. Непустой `DATABASE_URL` вызывает ошибку:
  PostgreSQL не реализован.
- `SURVEYOR_AUTO_MIGRATE=1` обновляет схему при старте; при `0` нужна актуальная схема.
  Отдельный запуск: `python -m app.migrate`.
- `SURVEYOR_BACKGROUND_MODE=embedded` оставляет периодические задания в сервере.
  Режим `external` требует отдельного `python -m app.worker` с тем же хранилищем;
  единственный планировщик защищён блокировкой. Запуск и остановка проверены локально.
- `tools/db_build.py` предназначен для первичной сборки, заменяет справочники в фиксированной
  `data/surveyor.db` и не учитывает `STORAGE_DIR`. Не использовать для миграции рабочей базы.
- Полная безопасная проверка: `sandbox/.venv/Scripts/python.exe tools/test_all.py`.
